# Elisa Hoeppers Site

Migração do site WordPress para stack moderna.

## Stack
- **Framework**: React + Vite + TypeScript (TanStack Start)
- **UI**: Tailwind CSS + shadcn/ui
- **Roteamento**: TanStack Router
- **Backend**: Supabase (em breve)

## Identidade Visual
- **Cores**: Verde oliva (`primary`), Creme (`background`), Sand (`footer`).
- **Tipografia**: Work Sans (corpo), Gotu (títulos).

## Como rodar
1. `bun install`
2. `bun dev`

## Estrutura de Rotas
- `/`: Home
- `/sobre`: Sobre mim
- `/agende-sua-aula`: Agendamento
- `/cursos`: Lista de cursos
- `/loja`: E-commerce
- `/blog`: Dicas e artigos
- `/painel`: Área do aluno
- `/bio`: Linktree style
- `/perfumista`: Landing específica
